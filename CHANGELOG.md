# Changelog

## 1.2.0

- Added visual_asset capability for frameworks, mechanisms, TOC, and vector icons.
- Added scoped research-skill fallback by quality gate.
- Added paper_to_deck workflow and academic-ppt-master candidate.
- Added SVG-first visual asset preparation and editability verification.
- Added Gate H for fallback provenance and visual asset fidelity.
- Added asset manifest and fallback log schemas.
- Added additional GitHub figure/deck repositories with license boundaries.
- Improved capability discovery with visual_asset and PPT auxiliary classification.

## 1.1.0

- Added official `Presentations` as a primary presentation capability.
- Added `template-creator` for reusable template workflows.
- Added `documents`, `pdf`, and `visualize` as explicit auxiliary capabilities.
- Added `univer-cli` for `.univer` / Univer Slides only.
- Added `ppt_core` / `ppt_auxiliary` / `not_ppt` relevance filtering to reduce false positives.
- Updated routing, conflict rules, docs, and tests.

## 1.0.0

- Added independent Slide Flow orchestrator.
- Added output modes: editable PPTX, image deck, HTML deck, template edit, image-to-editable, hybrid delivery.
- Added deck profiles and quality tiers.
- Added story/content/visual/production/render/QA/delivery stage contracts.
- Added conflict rules for competing PPT orchestrators and production engines.
- Added local PPT capability discovery.
- Added GitHub PPT skill ecosystem research and license boundaries.
