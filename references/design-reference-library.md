# Design Reference Library

## Purpose

Capture reusable design principles without copying copyrighted decks wholesale.

## Metadata

```yaml
reference_id:
source_url_or_path:
license_or_access:
page_or_section:
layout_pattern:
visual_hierarchy:
typography:
color_logic:
spacing:
chart_or_diagram_pattern:
why_it_works:
what_cannot_transfer:
```

## Rules

- Reference extracts patterns, not complete artwork.
- Preserve source/license/provenance.
- Do not copy logos, protected screenshots, illustrations or full slide compositions.
- Separate design principle from content-specific elements.
- A reference must be structurally matched to the current slide's job.
- When provenance is unknown, use it only as an internal visual principle and do not redistribute assets.

## Use in SlideFlow

1. Identify the slide's job.
2. Find a structurally similar reference.
3. Extract layout, hierarchy, spacing, typography and color logic.
4. Build a new slide with original content.
5. Compare current vs reference for hierarchy and legibility, not pixel-level similarity.
