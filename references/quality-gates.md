# Slide Quality Gates

## Gate A: Brief and audience

检查：

- 受众和场景；
- 演示型/阅读型；
- 时长、页数和目标行动；
- 输出形态、模板和品牌禁区；
- 是否需要讲稿/备注。

## Gate B: Story

检查：

- 一句话中心结论；
- 每页一个 message；
- 标题串联能讲出完整故事；
- 开场、论证、结论、行动的顺序；
- 页面是否服务于一个明确决策或理解目标。

## Gate C: Evidence and data

检查：

- 每个事实、数字和引用有来源；
- 图表使用真实数据；
- 不把定性判断伪装成统计；
- 不虚构市场、客户、实验结果或用户证言；
- 图注、来源和单位清楚。

## Gate D: Visual system

检查：

- 色板、字体、网格和间距一致；
- 主视觉服务信息，不是装饰噪声；
- 每页有明确视觉层级；
- 图表和 icon 语义一致；
- 模板/品牌规范被遵守。

## Gate E: Layout and legibility

检查：

- 无文字溢出、遮挡、裁切；
- 字号、对比度和行距适合观看距离；
- 图表标签可读；
- 页脚、页码、来源不冲突；
- 实际渲染页面通过视觉检查。

## Gate F: File and editability

检查：

- PPTX/PDF/HTML 能打开；
- 字体、图片、链接和媒体存在；
- 可编辑文件保留原生文本和对象；
- PDF 不是唯一源文件；
- 文件名、版本和导出格式正确。

## Gate G: Human approval

检查：

- 演讲者完整阅读；
- 事实、品牌、姓名、日期和模板确认；
- 最终输出形态和提交方式确认；
- 批准交付。

## Failure handling

1. 定位失败门和具体页面。
2. 只修复受影响页面/阶段。
3. 重新渲染并复查同一门。
4. 默认最多两轮。
5. 第三轮需要新素材、模板变化、用户明确要求或新风险。
6. 不能靠换一个 PPT skill 绕过失败门。
